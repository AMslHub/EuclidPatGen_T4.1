# Pitch Preset Guide

Empfehlungen für Euklid-Pattern, Scale und Spread zu jedem Pitch Preset.  
Notation: **H/L** = Hits / Length, z.B. `5/16` = 5 Hits in 16 Steps.

## Algorithmische Presets (gelb)

Werden bei jedem Laden neu generiert — kein festes Muster, sondern ein zufälliger Durchlauf basierend auf aktueller Scale/Root/Spread-Einstellung.

| Preset | Charakter | Scale | Spread | Hinweis |
| ------ | --------- | ----- | ------ | ------- |
| Brwn Slow | Sehr ruhige Brownian-Bewegung, kleine Schritte | Minor, Dorian | 2–3 Okt | Fast statisch, gut als Bordun |
| Brwn Mid | Mittlere Brownian-Bewegung | Minor, Phrygian, Dorian | 2–3 Okt | Klassischer zufälliger Walk |
| Brwn Fast | Wilde Sprünge, hohe Energie | Chromatic, Blues | 2–5 Okt | Viel Spread für maximale Variation |
| RndWlk Slow | 25% Wahrscheinlichkeit für Schritt — fast stehend | beliebig | 1–2 Okt | Erzeugt lange Töne mit gelegentlichem Wechsel |
| RndWlk Mid | 50% — ausgewogen | Major, Minor | 2 Okt | Guter Allrounder |
| RndWlk Fast | 85% — fast immer Bewegung | Dorian, Mixolydian | 2–3 Okt | Dichter als Brownian, aber geordneter |
| Drunk Walk | Brownian mit Anziehung zur Mitte | Major, Minor | 2–3 Okt | Kehrt immer wieder zum Zentrum zurück |
| Mk Stepwise | Markov: bevorzugt kleine Schritte, selten Sprünge | Major, Minor, Dorian | 2 Okt | Melodisch, fließend |
| Mk Harmon. | Markov: gewichtete Übergänge zwischen 5 Ankerpunkten | Major, Lydian, Harm. Min | 2 Okt | Strukturierter als Brownian |
| Mk Struktur | Markov: Richtungs-Zustand, läuft rauf/runter mit Wendepunkten | Major, Minor | 2–3 Okt | Klare Bögen, gut für melodische Entwicklung |

## Note-Effekte (grün)

Transformieren das zuletzt geladene (oder gebackene) Pattern.  
**Einmal drücken** = anwenden + backen. **Nochmal drücken** = rückgängig.  
**Enc1 Long Press** = aktuellen Zustand als neue Basis backen (Undo-Kette abschneiden).

| Effekt | Was passiert | Gut kombiniert mit |
| ------ | ------------ | ------------------ |
| Note Blur | Gleitender Mittelwert (links+mitte+rechts)/3 — glättet harte Sprünge | Nach Brwn Fast oder S&H um Energie zu dämpfen |
| Note Delay+1 | Verschiebt alle Steps um 1 nach rechts (mit Wrap) — invertiert gerade/ungerade Raster | Auf Acid, Detroit: bricht das rhythmische Raster auf |
| Note Dilat. | Morphologische Dilation: jeder Step = Maximum aus sich + Nachbarn — Spitzen breiten sich aus, Täler verschwinden | Auf S&H und Brwn Fast für Energie; Gegenteil zu Note Erode |
| Note Drunk | Jeder Step ±1 Skalenstufe zufällig verschoben — leichtes organisches Zittern | Nach Mk Stepwise für lebendige Nuancen |
| Note Erode | Morphologische Erosion: jeder Step = Minimum aus sich + Nachbarn — Täler breiten sich aus, Spitzen verschwinden | Auf laute, hohe Patterns für Dunkel/Schwere; Gegenteil zu Note Dilat. |
| Note Grad. | Morphologischer Gradient: Max−Min im Fenster — ruhige Steps → 0, Sprünge → hoher Wert (Energieprofil) | Als Basis für rhythmische Intensitätskurve; kombiniert mit Note Thin interessant |
| Note Echo | Ungerade Steps = verzögertes Echo des vorherigen geraden Steps | Auf jedes dichte Pattern |
| Note Freeze | Zweite Hälfte wird auf einen zufälligen Step eingefroren — Stotter-Effekt | Auf Cascade, Spiral für dramatischen Bruch |
| Note Inv | Spiegelt alle Werte vertikal: 255−x — Melodie wird zur Umkehrung | Auf Berlin, Mirror für harmonisches Spiegelbild |
| Note Oct+ | Ungerade Steps eine Oktave höher | Auf Acid, Minimal für Oktav-Bassline-Trick |
| Note Oct- | Ungerade Steps eine Oktave tiefer | Auf Floating, Berlin für Tiefe |
| Note Retro | Ungerade Steps rückwärts gespiegelt, gerade vorwärts | Auf Mirror, Cascade für Palindrom-Effekte |
| Note Rotate | Erste und zweite Hälfte tauschen die Plätze | Auf alle Presets — ändert Phrasierung komplett |
| Note Shadow | Ungerade Steps = nächsthöherer Skalenton (über IntervalMask steuerbar) | Mask nur "1+3" → immer Terz; "1+5" → immer Quinte |
| Note Spread | Erste Hälfte auf ganzes Pattern gestreckt (Zeitlupe) | Auf kurze, dichte Patterns |
| Note Stutter | Jede Note direkt wiederholt: A,A,B,B,C,C... | Auf Jazz Walk, Waltz für rhythmischen Effekt |
| Note Thin | Nur ungerade Steps behalten, gerade = Root (0) | Auf dichte Patterns um Luft zu schaffen |
| Note Tonic | Ungerade Steps = nächster Root-Ton (beliebige Oktave) | Gibt starkes tonales Zentrum; gut auf Balkan, Raga |
| Note Zip | Verzahnt erste und zweite Hälfte ineinander | Auf Spiral, Mirror für komplexe Verschachtelung |

### Effekt-Ketten (Beispiele)

```text
Detroit 1 → Note Delay+1 → Note Shadow   = sparse Bassline mit Terz-Echo
Brwn Mid  → Note Blur    → Note Thin     = ruhige, ausgedünnte Melodie
Cascade   → Note Inv     → Note Rotate   = gespiegelte, phasenverschobene Kurve
Acid 1    → Note Oct+    → Note Stutter  = Oktav-Stutter-Bassline
Mk Harmon.→ Note Tonic   → Note Blur     = harmonisch zentriert, weich
```

## Faustregeln

- **Viele Hits** (8/16+): nötig bei melodisch dichten Presets (Cascade, Spiral, Mirror), damit die Kurvenform hörbar wird
- **Wenige Hits** (2–5/16): bei Sparse-Presets (Detroit, Drone, Ominous) — Stille ist Teil des Musters
- **Dorian** ist für elektronische Musik fast immer eine sichere Wahl: moll-dunkel, aber mit der großen Sexte etwas offen
- **Spread erhöhen** macht bei Leapfrog, Floating, Spiral und den Berlin-Presets besonders viel aus
- **Rotation** verändert den Einstiegspunkt im Pattern — bei Acid und Gallop lohnt es sich, damit zu experimentieren
- **Algorithmische Presets** klingen bei jedem Laden anders — bei Scale/Root/Spread erst einstellen, dann laden
- **Note-Effekte** stapeln sich: mehrere hintereinander anwenden (ohne Undo) erzeugt immer komplexere Transformationen
- **Note Shadow** ist besonders flexibel: IntervalMask bestimmt den Sprung — nur "1" aktiv = Unisono, "1+5" = immer Quinte
